# portfolio v2 — Yandex.Forms Redesign

Статический сайт-кейс, свёрстанный пиксель-в-пиксель по макету
[dsgn-drafts → Portfolio final](https://www.figma.com/design/ydS8BJ0ACaLDooUdHHLsjK/dsgn-drafts?node-id=777-1731):
десктопный фрейм 1280 и мобильный 390.

## Структура

```
index.html          английская версия
ru/index.html       русская версия
build.mjs           генератор обеих версий (одна разметка + два словаря)
css/fonts.css       Gilroy / Gotham Pro / Satoshi, self-hosted, латиница + кириллица
css/style.css       вся вёрстка и адаптив
js/main.js          анимации: без зависимостей, без сборки
assets/fonts/       .woff2
assets/img/         экспорт картинок из макета (2×), взят из ~/Downloads
```

## Как править тексты

Тексты живут в `build.mjs` — два объекта `en` и `ru`. Правишь словарь и запускаешь:

```bash
node build.mjs
```

`index.html` и `ru/index.html` перегенерируются из одной разметки, поэтому
версии не расходятся. Править сгенерированные html руками не нужно.

## Локальный просмотр

```bash
python3 -m http.server 4173
```

## Адаптив

| Ширина | Поведение |
|---|---|
| ≥ 1320 | макет один в один, полотно 1280 |
| 1024–1319 | полотно масштабируется целиком (`zoom`), вёрстка не меняется |
| 760–1023 | перекладка: колонки схлопываются, коллажи сжимаются |
| ≤ 759 | мобильный фрейм макета: скриншоты старого интерфейса — карусели со свайпом и точками (и в секции «проблема», и в коллажах глав), текстовые карточки — горизонтальная лента, витрины на тёмной плашке под одной общей подписью, нижняя таблетка навигации |

## Анимации

- шапка прячется при скролле вниз и возвращается при скролле вверх;
- секции и карточки проявляются каскадом при попадании в кадр;
- заголовки глав проявляются «протяжкой» маски слева направо (буквы не режем
  на span-ы: inline-block ломает кернинг и слово становится шире макета);
- цифры в блоке «outcome» досчитываются до значения — в русской версии
  с запятой и своими подписями: `×1,5 раза`, `-2 мин`;
- свечения глав и художественные сцены двигаются параллаксом;
- герой: скриншот слегка отъезжает и наклоняется при уходе со страницы;
- на мобильном скриншоты старого интерфейса листаются пальцем: `scroll-snap`
  по слайдам, точки-индикатор под лентой синхронизированы со скроллом
  и кликабельны. Так же собрана галерея в секции «проблема»: оба старых
  скриншота лежат в одной карточке, широкая карточка со вторым на мобильном
  не выводится.

Всё уважает `prefers-reduced-motion: reduce`.

## Типографика

После каждого предлога ставится неразрывный пробел, чтобы предлог не висел
в конце строки. Расстановкой занимается `nbspify()` в `build.mjs`: он проходит
по готовой разметке, обрабатывает только текст между тегами и не трогает
атрибуты. Списки предлогов — `PREP_RU` и `PREP_EN` там же.

## Что отличается от макета

- **Опечатки в английском тексте поправлены:** `histrory → history`,
  `statictics → statistics`, `Filters work good → Filters work well`.
- **Русский текст местами подрезан**, чтобы влезть в карточки фиксированной
  высоты (коллажи глав, заголовки secций solution и outcome). Смысл сохранён,
  формулировки — из русского макета.
- **Заголовок первой главы** в русском макете — «главная и список»: с разрядкой
  40px он не помещается в 1280, поэтому у него разрядка 20px (`ch1Track`).
- **Блоки «Миграция тем» и «Проверка контраста»** в русском макете лежат
  в отдельном блоке «Плюшки» — текст взят оттуда.
- **Точки карусели** в макете белые (`#fff` 80%) — они лежат на цветном
  градиенте главы. У меня лента стоит чуть ниже, уже на светлом полотне,
  поэтому точки тёмные: `rgba(24,35,46,.8)` и `.25`. Размеры и шаг из макета:
  8 / 4px, шаг 14px.
- **Футер и мобильная шапка/таблетка навигации** — их в макете нет, взяты
  с [mokhova.github.io](https://mokhova.github.io/) как образец десктопа и
  мобильного. Футер убирается одним блоком в `build.mjs`.
