# Yandex.Forms Redesign — case study

Одностраничный лонгрид кейса, свёрстанный один-в-один по макету Figma
(`dsgn-drafts`, фрейм «MacBook Air - 1», ширина 1280).

## Как выложить на GitHub Pages

Git-репозиторий уже создан, всё закоммичено. Осталось три шага.

1. Создай пустой репозиторий на github.com — **без** README, .gitignore и
   лицензии. Имя: `katecherno.github.io` (сайт будет на
   `https://katecherno.github.io/`) или любое другое, например `yandex-forms`
   (тогда `https://katecherno.github.io/yandex-forms/`).

2. В терминале, из этой папки:

   ```bash
   ./deploy.sh https://github.com/<username>/<repo>.git
   ```

3. В репозитории: **Settings → Pages → Source: Deploy from a branch →
   Branch: `main` / `(root)`** → Save. Через минуту сайт поднимется.

Файл `.nojekyll` уже лежит в корне — он нужен, чтобы GitHub Pages не пытался
обрабатывать папки через Jekyll.

## Структура

```
index.html          вся разметка
css/fonts.css       @font-face
css/style.css       токены, типографика, секции, адаптив
js/main.js          скролл-анимации (без зависимостей)
assets/img/         50 картинок, выгруженных из Figma в @2x
assets/fonts/       Gilroy, Gotham Pro, Satoshi (woff2)
```

## Что внутри по анимациям

- прогресс-бар чтения вверху страницы;
- шапка прячется при скролле вниз и возвращается при скролле вверх,
  активный раздел подсвечивается в навигации;
- hero: скриншот уходит в перспективу, заголовок всплывает вверх;
- параллакс на всех цветных блобах и на стеклянном контейнере hero;
- появление секций по мере прокрутки, карточки — каскадом;
- счётчики на цифрах `1.5x` и `-2min`;
- всё выключается при `prefers-reduced-motion: reduce`.

## Шрифты и лицензии

`Gilroy` и `Gotham Pro` — коммерческие гарнитуры. Файлы взяты из локальной
коллекции на этом компьютере и положены в `assets/fonts/`. Перед публикацией
в открытый репозиторий убедись, что лицензия разрешает web-embedding.

Если публиковать их нельзя — просто удали соответствующие `.woff2`:
вёрстка сама перейдёт на `Satoshi` (открытая лицензия, лежит рядом), ничего
править в коде не нужно. Геометрия блоков не изменится, поедет только текст.

## Адаптив

Три режима.

**От 1320px** — макет один в один, полотно 1280px по центру.

**1024–1319px** — полотно масштабируется целиком через `zoom`. Пропорции
и композиция не меняются, просто всё немного меньше.

**До 1024px** — настоящая перекладка. Колонки схлопываются в одну, коллажи
из абсолютной раскладки становятся вертикальным списком карточек, скриншоты
тянутся на всю ширину, у заголовков и текста включается `clamp()`.

Отдельная история — художественные сцены в блоках «So what's the design?».
Там картинки разложены абсолютно и композиция и есть дизайн, ломать её нельзя.
Поэтому `fitStages()` в `js/main.js` считает реальные границы картинок внутри
сцены, обрезает пустое поле (место, где на десктопе стоял текст) и вписывает
сцену в ширину экрана через `zoom`. Текст при этом уезжает над картинкой —
одинаково во всех карточках.

Ниже 760px в шапке остаётся только навигация по главам и аватар, контакты
живут в футере.

## Отличия от макета — осознанные

- Зернистая текстура фона сделана процедурно (SVG `feTurbulence`) вместо
  растровой картинки — это экономит вес и не мылится на ретине.
- Размытые эллипсы-блобы сделаны CSS-градиентами с `filter: blur()`
  вместо экспорта векторов.
- Внизу добавлен небольшой футер с контактами — в макете страница
  обрывается на последнем блоке.

## Что ещё внутри

- `deploy.sh` — публикация одной командой.
- `assets/favicon.svg` — иконка вкладки.
- `assets/og.png` — превью для соцсетей. `og:image` указан относительным
  путём: большинство краулеров резолвят его от адреса страницы. Если Телеграм
  или LinkedIn будут капризничать, пропиши в `index.html` абсолютный URL
  вида `https://<username>.github.io/<repo>/assets/og.png`.
- Анимации целиком отключаются при `prefers-reduced-motion: reduce`,
  на узких экранах параллакс не включается вовсе.
- Все картинки, кроме hero и аватара, грузятся лениво.
